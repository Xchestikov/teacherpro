# TeacherPro — доступ без VPN

## Факты проверки, 20 октября 2026

- Приложение и сам FirstVDS доступны, но мобильный браузер без VPN не может обратиться к Supabase напрямую.
- FirstVDS может обращаться к Supabase по IPv4 (проверено исходящим HTTPS-запросом).
- Пользователь `teacherpro-deploy` имеет SSH и права на `/srv/teacherpro`, но не имеет root или sudo для изменения Nginx.
- В виртуальном хосте HTTPS есть только include для Let's Encrypt; нет пользовательского include, куда можно безопасно записать proxy-location без root.

## Реализовано

1. Supabase SDK размещён локально в `vendor/supabase-sdk.js`, исключая сетевую зависимость от jsDelivr.
2. Загрузка и действия авторизации имеют ограничение ожидания, чтобы не оставлять страницу или кнопку в бесконечном состоянии.
3. Перед созданием Supabase-клиента проверяется `/supabase/auth/v1/health`. Выбирается свой HTTPS-прокси **только** при явном HTTP-заголовке `X-TeacherPro-Proxy: v1` и ответе без 5xx. Если прокси ещё не установлен, остаётся старый прямой URL, без потери токенов пользователя.
4. Ключ хранения сессии Supabase сохраняется прежний `sb-egopcojrzklvytcuhpov-auth-token`.
5. Релиз автоматически копирует подготовленные инфраструктурные файлы в `/srv/teacherpro/infra/`, **не в публичный webroot**.
6. `infra/install-supabase-proxy.sh` делает резервные копии, добавляет безопасные директивы только в конфигурацию нужного домена, проверяет `nginx -t`, перезагружает Nginx, выполняет HTTP health check и откатывает конфигурацию при ошибке.

## Единственная недоступная через существующую роль операция

Разовое выполнение от root непосредственно в административной консоли FirstVDS:

```bash
bash /srv/teacherpro/infra/install-supabase-proxy.sh
```

Не запускать до завершения успешного деплоя соответствующего релиза. Перед запуском администратор может просмотреть скрипт через `less /srv/teacherpro/infra/install-supabase-proxy.sh`.

После успешной установки **не нужно** менять `cloud-config.js` или перезаливать приложение: клиент сам выберет свой прокси после обновления страницы.

## Проверки после установки

- В ответе `https://teacherpro-app.ru/supabase/auth/v1/health` присутствует `X-TeacherPro-Proxy: v1`.
- На LTE без VPN открывается TeacherPro и проходит вход в существующий аккаунт.
- Проверяются список учеников, занятия, оплаты и синхронизация между двумя устройствами.
- Проверяются восстановление пароля и подтверждение регистрации: существующие ссылки в email могут вести непосредственно на домен Supabase, поэтому для полного отсутствия VPN может дополнительно потребоваться настройка email-шаблонов Auth.
- При сбоях прокси Nginx автоматически не переключается на прямой upstream; резервный прямой URL выбирается при следующем запуске клиента, если health endpoint не отвечает корректно.

Никаких миграций данных и изменений RLS не требуется.
