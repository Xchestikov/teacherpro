# TeacherPro — этап 1: стабильность и исправления

Дата подготовки: 15 октября 2026 года.

## Уже изменено в отдельной ветке

- Исправлена упаковка релиза: `calendar-stage1.js` теперь включён в список файлов, отправляемых на собственный сервер.
- Добавлена проверка согласованности ресурсов: локальные файлы из `index.html` и `sw.js` должны существовать и находиться в списке проверки и отправки.
- При удалении урока с фактическим списанием явно сообщается о возврате занятия в остаток. Списание возвращается только при наличии связи с абонементом или старым счётчиком.
- Добавлены браузерные регрессионные сценарии: 120-минутное событие в сетке (включая кликабельность второй часовой строки), контекстное меню, отмена/подтверждение удаления со списанием.
- Подготовлен GitHub Actions workflow с проверками синтаксиса, состава релиза и Playwright в Chromium на изолированном тестовом Supabase.

## Выполненные автоматические проверки

- GitHub Actions: статические проверки JS и полноты состава релиза — успешно.
- Playwright (Chromium, изолированный тестовый Supabase): 14 из 14 сценариев прошли на коммите `ecfd28a` 15 октября 2026 года. Скриншоты сохранены в артефакте запуска GitHub Actions № 38717757573.

## Остаётся проверить перед публикацией

- Реальное восстановление сессии при задержанной загрузке SDK и на физическом телефоне.
- Визуальное состояние календаря на ширинах 320/360/390/768/1280 px; тесты автоматически делают снимки, но их необходимо просмотреть.
- Изоляция между реальными пользователями Supabase, синхронизация с реальной сетью.
- Возврат списаний во всех старых вариантах данных.
- Публикация и HTTP-проверка собственного сервера: запрещено до согласования пользователя.

## Критерии приёмки этапа

1. Уроки 30, 60, 90 и 120 минут занимают пропорциональную высоту, а перекрытые сеткой фрагменты остаются видимыми.
2. Удаление проведённого урока требует подтверждения, объясняет возврат занятия, не выполняет возврат при отказе.
3. Сеанс после F5 не показывает форму входа при действительной сессии.
4. Весь состав файлов приложения доставляется при деплое; неправильный состав обнаруживается CI до публикации.
5. Тесты Playwright и мобильные скриншоты рассмотрены перед выпуском.

## Вне этапа

Разработка календаря V2, новые состояния пропусков, автоматическое расписание и визуальный редизайн будут отдельными задачами после согласования. DNS/доступ без VPN временно отложены. База реальных учеников не меняется.
