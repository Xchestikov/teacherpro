# Ритм — личная версия

Локальный MVP аналога RytmSpace для личного использования.

## Что работает
- Главная: занятия сегодня, клиенты, доход, внимание по абонементам
- Расписание на неделю
- Создание и редактирование занятий
- Клиенты
- Абонементы и остатки
- Оплаты
- Настройки
- Локальное хранение данных в браузере
- Экспорт данных в JSON

## Запуск
Самый простой вариант: открыть `index.html` в браузере.

Для корректной работы можно запустить локальный сервер:

```bash
python -m http.server 8080
```

Затем открыть http://localhost:8080

## Облачная синхронизация (Supabase)

1. Создай проект в Supabase.
2. В Supabase Dashboard открой SQL Editor и выполни содержимое `supabase/schema.sql`.
3. В Project Settings → API скопируй Project URL и publishable/anon key.
4. Впиши их в `cloud-config.js` в `RITM_SUPABASE_URL` и `RITM_SUPABASE_ANON_KEY`. Не используй `service_role` key.
5. Запушь изменения в GitHub: Vercel автоматически создаст новый деплой.
6. Открой сайт, зарегистрируйся с email и паролем. Если для проекта включено подтверждение email, подтверди адрес перед входом.
7. При первом входе, если облачная запись ещё не создана, текущие данные этого браузера будут загружены в облако. Если облачные данные уже существуют, они станут основной версией.

В облаке хранится единый JSON-профиль пользователя в таблице `app_data`; Row Level Security ограничивает чтение и изменение строк только их владельцем. В браузере остаётся локальная копия для восстановления интерфейса. Синхронизация сохраняет изменения после паузы в 0,5 секунды.

Важно: это первый этап синхронизации. Одновременное редактирование на нескольких устройствах пока не разрешает конфликты автоматически — при редких одновременных изменениях последняя сохранённая версия может перезаписать более раннюю. Перед переходом на реальные финансовые данные проверь миграцию и сделай экспорт резервной копии.
